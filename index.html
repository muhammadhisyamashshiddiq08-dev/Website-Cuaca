Tentang Aplikasi

Platform informasi cuaca yang dirancang untuk memberikan data akurat dan real-time bagi pengguna di Indonesia.

Kami mengintegrasikan API dari Open-Meteo untuk memberikan data suhu, kelembapan, kecepatan angin, dan prakiraan cuaca hingga 5 hari kedepan. Aplikasi ini dibangun dengan teknologi HTML, CSS, Bootstrap, dan JavaScript modern.
